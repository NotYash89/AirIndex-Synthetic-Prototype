Compliance & ethical scraping
How the production scraper stays on the right side of site terms
robots.txt respected

Each source's rules parsed before any crawl. Paths marked disallowed are skipped.

Rate limits

Requests throttled well below the source's published limit. Bursts are queued, never dropped on the server.

No login bypass

Only publicly visible fares are read. No CAPTCHA solving, no session hijacking, no user accounts.

Terms-of-service review

Each source's ToS reviewed before onboarding. Sources that prohibit automated access are excluded.

Attribution

Every observation carries a source tag and timestamp. Data is not republished as the source's own.

Audit trail

Raw quotes preserved with a versioned parser trail. Any published number traces back to the exact request.
